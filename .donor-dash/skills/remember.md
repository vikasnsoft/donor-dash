# Remember Skill

## Purpose
Maintain project knowledge across sessions. Consult context files before starting work.

## When to Invoke
- At the start of any session
- When unsure about project conventions
- When the user asks "what's the status of X"
- Before making architectural decisions

## What to Remember

### Project State
- What's built, what's planned (progress-tracker.md)
- Current phase and milestones
- Known issues and technical debt

### Architecture
- Module structure and boundaries
- Data flow patterns
- Decision records

### Conventions
- Code standards and naming
- API design patterns
- UI patterns
- Financial rules

## Process

1. **Check progress-tracker.md** — understand what's complete
2. **Check relevant context files** — for the task at hand
3. **Check decision records** — for relevant ADRs
4. **Check taste** — for learned preferences
5. **Proceed with confidence** — you now have full context

## Rules
- Never assume project state from a previous session
- Always verify assumptions against context files
- Update progress-tracker.md when completing milestones
