# Donor Dash

Community Finance Platform for events, donations, collections, and shared expenses.

Built with Next.js, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Getting Started

```bash
git clone https://github.com/vikasnsoft/donor-dash.git
cd donor-dash
npm install
npm install --prefix frontend
npm run dev
```

## Tech Stack

- **Framework**: Next.js 16 + React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **UI Components**: shadcn/ui + Radix UI
- **State Management**: TanStack Query + Zustand
- **Backend**: Express 5 + MongoDB + Mongoose
